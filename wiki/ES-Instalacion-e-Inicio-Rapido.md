# Instalación e inicio rápido

## Requisitos

- Windows 10 o Windows 11.
- Playnite 10.x.
- Uno o varios mandos compatibles con Windows.

## Instalación

1. Descarga el último `.pext` desde [Releases](https://github.com/Naerian/playnite-nx-session-controller-manager/releases/latest).
2. Ábrelo o arrástralo sobre Playnite.
3. Reinicia Playnite cuando se solicite.

## Primera configuración

Abre `Complementos > Configuración de extensiones > Genérica > Controller Manager`.

1. En **Mandos**, comprueba que cada mando físico aparezca una sola vez.
2. Asigna nombres e iconos opcionales y guarda.
3. Usa **Probar** para abrir la pestaña Tester de ese mando, o la vibración para identificarlo.
4. Mantén activa **Avanzado > Monitorización**.
5. Configura el acceso de Desktop, la notificación Fullscreen y el overlay en **Apariencia**.
6. Conserva inicialmente la protección automática/adaptativa.

Si el complemento antiguo **Gamepad Tester** sigue instalado, desinstálalo. Las dos extensiones no pueden reclamar el mismo `SourceName` Fullscreen `GamepadTester`.

## Primera prueba de protección

1. Inicia desde Playnite un juego offline para un jugador.
2. Usa botones o sticks del mando elegido.
3. Desconéctalo durante la partida.
4. Comprueba que el overlay aparezca tras el margen configurado.
5. Reconéctalo o utiliza otro mando disponible cuando se permita el relevo.

Empieza con **Solo overlay**. Activa una tecla de pausa únicamente tras confirmar qué tecla abre de forma segura el menú del juego. La pausa forzada es una opción avanzada que debe probarse por juego.
