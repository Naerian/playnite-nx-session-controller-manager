# Controller Session Manager 1.0.0

Controller Session Manager 1.0.0 is the first stable release of the Playnite controller-awareness and session-protection extension.

## Highlights

- Tracks intentional controller participation and adapts between single-player handover and local multiplayer.
- Displays configurable Fullscreen connection notifications and a controller-aware disconnect overlay.
- Supports conservative pause-key delivery, optional watchdog-backed offline force-pause, and online-session fallback.
- Adds custom controller names and icons, vibration identification, Desktop quick access and theme integration.
- Reports XInput/SDL battery states and verified DualSense/DualShock 4 HID battery states without inventing unsupported values.
- Exports a privacy-conscious support report with anonymized identities and a recent incident timeline.
- Includes 12 localized interfaces with English fallback and complete English/Spanish Wiki documentation.

## Safety and compatibility

The overlay runs out of process and does not inject into games. Fullscreen keeps a strict SDL safety boundary. Pause actions are opt-in and use foreground/process/online evidence conservatively. Unsupported battery protocols remain explicitly unknown.

See the [README](https://github.com/Naerian/playnite-nx-session-controller-manager#readme) and [Wiki](https://github.com/Naerian/playnite-nx-session-controller-manager/wiki) for installation, configuration and troubleshooting.
